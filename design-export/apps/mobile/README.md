## 1. Entry point & how to run
**Open `apps/mobile/Smartout Mobile Version 1.html`.** Single entry file — the living mobile app.

It loads, in order:
1. Google Fonts (Instrument Serif, Geist, Geist Mono)
2. **`../web/shared/styles.css`** — the Nordic Split design system (tokens + components). **Reused, never forked.** This is the binding visual system; mobile inherits warm cream/black, orange brand, semantic colors, fonts, radii, shadows, and **dark mode** (`[data-theme="dark"]`) for free.
3. `mobile.css` — the mobile-only **shell + component layer** (everything prefixed `.m-*`): phone canvas, topbar, bottom tab bar, cards, task rows, quick chips, on-shift hero, Botsson strip/sheet, toasts, bottom sheets, lists. Built entirely on the shared tokens.
4. **`../web/shared/data.js`** — shared mock data / world / cast → `window.SmartoutData` (USERS, ME, TASKS, ROUTINES, …). Extend **there**, don't invent parallel data.
5. `shell.jsx` — the mobile shell (chrome + state + router + Botsson). Exposes `window.MIc`, `window.useM`, `window.M`, `window.SmartoutMark`, `window.__SmartoutMobileBoot`.
6. `hjem.jsx` — the **Hjem / Min dag** page (rich; the centerpiece).
7. `screens.jsx` — the **Opplæring (trening)**, **HMS (sikkerhet)** and **Lønn (lonn)** sub-screens, ported from the repo's `(home)/training.tsx`, `(home)/hms.tsx` and `(me)` screens.
8. `pages.jsx` — the lighter satellite pages (Kalender, Vakter, Oppgaver, Chat, Mer).
9. boot script calls `window.__SmartoutMobileBoot()`.

**Lighter than web on purpose:** web has ~12 page modules split across many files. Mobile keeps it to **one shell + one rich page + one file of lighter pages** for now. Add a rich page as its own file (like `hjem.jsx`) when it earns the weight; keep small/related screens grouped in `pages.jsx`.

## 2. Architecture (mirror of web, condensed)
- **Phone canvas, no bezel** (`.m-app`): a responsive phone-width column (max 430px). On phones it fills the viewport; on desktop it centers on a warm backdrop with rounded corners + soft shadow (a device *suggestion*, not a bezel). `viewport-fit=cover` + `env(safe-area-inset-bottom)` respected.
- **Shell = `MApp`** (`shell.jsx`): holds app state (`tab`, `mode`, `theme`) persisted to `localStorage['so_mobile_v1']`. Renders `<Topbar>`, the active page inside `.m-scroll`, `<BottomNav>`, the toast stack, and the Botsson `<BotssonSheet>` overlay.
- **Context:** `window.useM()` returns `{ ME, mode, setMode, theme, toggleTheme, tab, navigate, toast, badges, openBotsson }`. Every page consumes this — no prop threading.
- **Pages register** into `window.SO_M_PAGES[route]` (mirror of web's `SO_PAGES`). The 5 routes are the 5 bottom tabs.
- **Icons:** `<MIc n="name" s={size} c={color} sw={stroke} />`. Glyph map (`ICONS`) at the top of `shell.jsx` — a Lucide-style subset lifted from the web shell. Add glyphs there.
- **Toasts/undo:** `toast('Lagret', { undo: () => … })` from `useM()`.
- **Numbers/time/IDs:** `.mono` / `var(--font-mono)` (Geist Mono).

### Bottom tab bar (`TABS` in `shell.jsx`)
`Kalender · Vakter · [⊕ FAB] · Chat · Mer` — the center is the orange Smartout brand FAB. **Tap → Hjem** (the Min dag centerpiece); **long-press / right-click → Hurtigvalg (Add) sheet** (quick-create + "Spør Botsson"). The FAB carries a small `+` corner badge to advertise create. Badges via `badges` map (`tasks`, `chat`).

**Sub-pages & back:** `trening`, `sikkerhet`, `lonn`, `oppgaver` are routes but **not** bottom tabs. The shell keeps a `histRef` nav stack; `navigate(route)` pushes, `back()` pops. When the active route is a sub-page (`SUBPAGES` map in `shell.jsx`), the topbar swaps its left avatar for a **back arrow** + the page title — so there's no double header. Reach the sub-pages from the Hjem **ActionBar** or the **Mer** quick links.

### Two modes (employee ⟷ manager), like web
- **`privat`** (Ansatt) — the frontline experience. Hjem = on-shift hero + quick actions + Botsson brief + "Mine oppgaver i dag" + Siste nytt.
- **`admin`** (Leder) — a mobile manager brief. Hjem = pulse stat strip + Botsson brief + "Krever handling nå" + manager quick actions + "På vakt nå" roster.
- Switched from the **Mer** screen (segmented Ansatt/Leder). Same 5 tabs in both modes; **content adapts to mode** (the lighter way to do web's two nav sets). `ME` = Maria A. (Driftsleder, treated as `canAdmin`), consistent with web's same-user/two-modes model.

## 3. Design direction (binding)
Inherits the web spec verbatim — see `apps/web/README.md` §6 and `uploads/SMARTOUT-DESIGN-SPEC.md`.
- **Feel (mobile):** **action-first** — get the user through their next task/shift fast, one-handed. Calm, warm, glanceable.
- **Color/type/spacing:** from `../web/shared/styles.css` tokens only. Warm cream bg, warm black fg, orange brand; muted green / amber / restrained red status. Instrument Serif (display), Geist (UI), Geist Mono (numbers). **Never emoji in chrome/labels** (decorative 🎂/🎉 inside human content like greetings/announcements is OK — mirror the original concept). Never cold grey/blue or pure white/black.
- **Both light + dark must stay polished** — verified on Hjem (both modes) + Mer.
- **AI (Mr. Botsson) is assistive, never magical** — the morning brief + chat sheet explain reasoning ("Hvorfor?" with sources), suggest, and ask before acting; everything is undoable via toast.
