# Smartout — Konkurrentanalyse

**Versjon:** 2.0
**Dato:** 13. april 2026
**Formål:** Enkel oversikt over konkurrenter i Norden og Europa, mappet med pris og funksjoner.

## 1. Nordiske konkurrenter

### Planday (Danmark / UK)

| | |
|---|---|
| **Prismodell** | Per ansatt per måned |
| **Laveste plan** | ~45 NOK/bruker/mnd |
| **Middels plan** | ~75 NOK/bruker/mnd |
| **Typisk kostnad (20 ansatte)** | ~900 NOK/mnd |
| **Gratis plan** | Nei |
| **Fokus** | Vaktplanlegging, tidsregistrering |

**Funksjoner:** Vaktplan, stemplingsur, lønnseksport, fravær, multi-location. Dokumenthåndtering og kompetanse kun på høyere planer. Ingen onboarding, ingen IK-mat, ingen AI.

## 4. Konkurrentlandskap per funksjonsområde

Hvilke konkurrenter opererer i hvert funksjonsområde?

| Funksjonsområde | Nordiske aktører | Internasjonale aktører | Typisk prisrange |
|---|---|---|---|
| **Vaktplanlegging** | Planday, Smartplan, Workfeed, PowerPlan, Timegrip, Tidsbanken | 7shifts, Homebase, When I Work | 350–1 600 NOK/mnd |
| **Stemplingsur** | Planday, Tidsbanken, Timegrip, Smartplan, PowerPlan | 7shifts, Homebase, Connecteam | Ofte inkludert i vaktplan |
| **Oppgaver/rutiner** | Runwell | Trail, Lumiform, Jolt | Separate systemer |
| **Opplæring** | Learnster, Learnifier, Runwell (betalt) | Connecteam (betalt) | Egne plattformer |
| **IK-mat / HACCP** | eSmiley, Tracsa, FoodDocs, Runwell | (nisjemarked) | Egne systemer / del av Runwell |
| **Kommunikasjon** | PowerPlan (chat) | Slack, Teams, Connecteam | Separate apper |
| **AI-vaktplanlegging** | Timegrip, Workfeed (betalt) | (ingen i dette segmentet) | — |
| **AI-assistent** | (ingen) | (ingen i dette segmentet) | — |

### Observasjoner

- Ingen nordisk konkurrent dekker alle funksjonsområdene i ett system
- Runwell er nærmest en alt-i-ett, men mangler egen vaktplan og stemplingsur
- Timegrip har AI-drevet vaktplanlegging, men ingen opplæring eller IK-mat
- De fleste tar betalt per ansatt — noen per lokasjon, noen per avdeling
- Gratis planer finnes hos 7shifts, Homebase, Workfeed og Connecteam (alle med begrensninger)
