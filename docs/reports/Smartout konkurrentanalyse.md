## 1. Nordiske konkurrenter

### Planday (Danmark / UK)

| | |
|---|---|
| **Prismodell** | Per ansatt per måned |
| **Laveste plan** | ~45 NOK/bruker/mnd |
| **Middels plan** | ~75 NOK/bruker/mnd |

## 4. Konkurrentlandskap per funksjonsområde

Hvilke konkurrenter opererer i hvert funksjonsområde?

| Funksjonsområde | Nordiske aktører | Internasjonale aktører | Typisk prisrange |
|---|---|---|---|
| **Vaktplanlegging** | Planday, Smartplan, Workfeed, PowerPlan, Timegrip, Tidsbanken | 7shifts, Homebase, When I Work | 480–1 100 NOK/mnd |
| **Stemplingsur** | Planday, Tidsbanken, Timegrip, Smartplan | 7shifts, Homebase, Connecteam | Ofte inkludert i vaktplan |
| **Oppgaver/rutiner** | (ingen dedikert nordisk) | Trail, Lumiform, Jolt | Separate systemer |
| **Opplæring** | Learnster, Learnifier, Runwell | Connecteam (betalt) | Egne plattformer |
| **IK-mat / HACCP** | eSmiley, Tracsa, FoodDocs | (nisjemarked) | Egne IK-systemer |
| **Kommunikasjon** | (ingen dedikert) | Slack, Teams | Separate apper |
| **AI-assistent** | (ingen) | (ingen i dette segmentet) | — |

### Observasjoner

- Ingen nordisk konkurrent dekker alle funksjonsområdene i ett system
- IK-mat og opplæring finnes kun som separate systemer hos konkurrentene
- Ingen konkurrent tilbyr AI-assistanse i dette segmentet
- De fleste tar betalt per ansatt — noen per lokasjon, noen per avdeling
- Gratis planer finnes hos 7shifts, Homebase, Workfeed og Connecteam (alle med begrensninger)
