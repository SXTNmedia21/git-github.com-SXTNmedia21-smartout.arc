# Smartout — Tre nivåer av onboarding-hjelp

**Versjon:** 1.0
**Dato:** 13. april 2026
**Formål:** Definere hva hver onboarding-pakke inneholder, slik at kunden vet hva de får og sales vet hva de selger.

---

## Oversikt

Onboarding er en engangskostnad, separat fra lisensen. Den dekker arbeidet med å få kunden opp og kjøre på Smartout. Ikke alle kunder trenger like mye hjelp.

| | Small | Medium | Heavy |
|---|---|---|---|
| **Pris** | 5 500 NOK | 15 500 NOK | 25 500 NOK |
| **Tidsramme** | 2 uker | 6 uker | 3 måneder |
| **Hvem det passer for** | Selvgående kunder med enkel drift | Kunder med flere avdelinger eller behov for tilpasning | Kjeder, multi-location, kompleks drift |
| **Smartouts involvering** | Lav | Middels | Høy |

> Onboarding-pakke utløser automatisk årslisens.

---

## Small — "Vi setter deg i gang"

**Pris:** 5 500 NOK (engangs)
**Tidsramme:** 2 uker
**Passer for:** Enkeltstående restauranter, kafeer, mindre butikker. Kunden er teknisk komfortabel og har enkel organisasjonsstruktur.

### Hva er inkludert

| Aktivitet | Beskrivelse |
|---|---|
| **Kickoff-møte** | 1 time video/telefon. Kartlegger behov, avtaler plan. |
| **Workspace-oppsett** | Smartout oppretter workspace, inviterer admin, setter grunnkonfigurasjon. |
| **Avdelinger og roller** | Oppretter avdelingsstruktur og standard roller basert på kundens info. |
| **Importstøtte** | Hjelp med import av ansattliste (CSV eller manuelt). |
| **Admin-opplæring** | 1 time opplæring for admin (vaktplan, ansattoversikt, grunnfunksjoner). |
| **E-post-support** | Tilgjengelig i 2 uker etter oppstart. |

### Hva kunden gjør selv

- Legger inn detaljerte ansattdata (kontrakter, tilgjengelighet)
- Oppretter vaktlister
- Konfigurerer oppgaver og rutiner
- Setter opp opplæringsinnhold (policyer, protokoller)
- Konfigurerer IK-mat (dersom relevant)

### Leveranse

Etter 2 uker har kunden:
- Fungerende workspace med admin-tilgang
- Avdelingsstruktur på plass
- Ansatte importert
- Admin kan bruke grunnfunksjonene selvstendig

---

## Medium — "Vi bygger det sammen"

**Pris:** 15 500 NOK (engangs)
**Tidsramme:** 6 uker
**Passer for:** Kunder med 2–5 avdelinger, behov for tilpassede rutiner, eller overgang fra annet system (Planday, eSmiley, etc.).

### Hva er inkludert

Alt fra Small, pluss:

| Aktivitet | Beskrivelse |
|---|---|
| **Behovsanalyse** | Grundigere kartlegging (2 timer). Gjennomgang av eksisterende rutiner og systemer. |
| **Komplett oppsett** | Smartout setter opp hele workspace: avdelinger, roller, posisjoner, team, åpningstider. |
| **Rutiner og sjekklister** | Smartout oppretter daglige oppgaver, rutiner og sjekklister basert på kundens behov. |
| **IK-mat-oppsett** | Konfigurering av temperaturlogg, renholdsrutiner, avviksmal. |
| **Kontraktsmaler** | Oppretter kontraktsmaler tilpasset kundens behov. |
| **Opplæring for ledere** | 2 timer opplæring for avdelingsledere/managere (utover admin). |
| **Onboarding-innhold** | Smartout lager grunnleggende opplæringsinnhold (velkomstprotokoll, HMS-grunnlag). |
| **Migrasjonshjelp** | Hjelp med overgang fra eksisterende system (eksport/import, parallellkjøring). |
| **Oppfølgingsmøte** | 1 møte etter 3 uker for justering og spørsmål. |

### Hva kunden gjør selv

- Finjusterer oppgaver og rutiner etter eget behov
- Utdyper opplæringsinnhold med bedriftsspesifikk kunnskap
- Ruller ut til ansatte (med støtte fra Smartout)

### Leveranse

Etter 6 uker har kunden:
- Fullt konfigurert workspace med alle avdelinger
- Daglige rutiner og sjekklister på plass
- IK-mat konfigurert (dersom relevant)
- Kontraktsmaler klare
- Ledere opplært
- Grunnleggende opplæringsinnhold for ansatte

---

## Heavy — "Vi tar oss av alt"

**Pris:** 25 500 NOK (engangs)
**Tidsramme:** 3 måneder
**Passer for:** Kjeder (5+ lokasjoner), hoteller, multi-location-operasjoner, bedrifter med komplekse tariffavtaler, eller kunder som vil ha en ferdig plattform uten egeninnsats.

### Hva er inkludert

Alt fra Medium, pluss:

| Aktivitet | Beskrivelse |
|---|---|
| **Strategiworkshop** | Heldags workshop (fysisk eller digital) med ledelsen. Kartlegger hele driften. |
| **Komplett innholdsproduksjon** | Smartout produserer alle policyer, protokoller, prosedyrer og opplæringsmateriell. |
| **Sesongkonfigurasjon** | Oppsett av sesonger, budsjetter, dagfaktorer og timefaktorer. |
| **Tariffoppsett** | Konfigurering av tariffavtaler, tillegg, overtidsregler. |
| **Multi-location-oppsett** | Fullstendig oppsett for alle lokasjoner med riktig struktur. |
| **Ansatt-onboarding** | Smartout kjører første onboarding-runde med 1–2 grupper ansatte. |
| **Leder-workshop** | Halv dag dedikert opplæring for alle ledere/managere. |
| **Go-live-støtte** | Smartout er tilgjengelig første uke etter lansering (chat + telefon). |
| **Månedlig oppfølging** | 3 oppfølgingsmøter (måned 1, 2 og 3) for justering og optimalisering. |
| **Dedikert kontaktperson** | Én person hos Smartout eier hele onboarding-prosessen. |

### Hva kunden gjør selv

- Deltar i workshop og møter
- Godkjenner innhold og oppsett
- Gir tilgang til eksisterende systemer for migrasjon

### Leveranse

Etter 3 måneder har kunden:
- Komplett plattform med alle moduler konfigurert
- Alt opplæringsinnhold produsert og tilgjengelig
- Alle lokasjoner og avdelinger på plass
- Sesonger og budsjetter konfigurert
- Ledere og første gruppe ansatte onboardet
- 3 måneder med oppfølging gjennomført

## Sammenligning

| | Small | Medium | Heavy |
|---|---|---|---|
| Kickoff-møte | 1 time | 2 timer | Heldags workshop |
| Workspace-oppsett | Grunnleggende | Komplett | Komplett + multi-location |
| Avdelinger/roller | Standard | Tilpasset | Fullt tilpasset |
| Rutiner/sjekklister | Nei | Ja | Ja + alt innhold |
| IK-mat-oppsett | Nei | Ja | Ja |
| Kontraktsmaler | Nei | Ja | Ja + tariff |
| Opplæringsinnhold | Nei | Grunnleggende | Komplett produksjon |
| Sesong/budsjett | Nei | Nei | Ja |
| Admin-opplæring | 1 time | 1 time | 1 time |
| Leder-opplæring | Nei | 2 timer | Halv dag |
| Ansatt-onboarding | Nei | Nei | 1–2 grupper |
| Migrasjonshjelp | Nei | Ja | Ja + parallellkjøring |
| Oppfølgingsmøter | Nei | 1 møte | 3 møter |
| Dedikert kontakt | Nei | Nei | Ja |
| Go-live-støtte | E-post (2 uker) | E-post (6 uker) | Chat + telefon (1 uke) + 3 mnd |

## Åpne spørsmål

1. Skal det finnes en **fjerde pakke** for enterprise (custom pris, custom scope)?
2. Skal onboarding-pakke fortsatt **utlose årslisens automatisk**, eller kobles fra?
3. Skal deler av Medium/Heavy kunne **kjopes som tillegg** til Small?
4. Skal det finnes en **self-service onboarding** uten kostnad (kun dokumentasjon + tutorials)?
5. Skal prisene **justeres** i forbindelse med ny prismodell?
