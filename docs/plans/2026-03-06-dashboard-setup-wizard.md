# Dashboard Setup Wizard: Operational Readiness Journey

This document outlines the post-onboarding "click-and-choose" workflow. Once the admin completes the initial Botsson onboarding and lands on the dashboard, we transition into the **Operational Setup Wizard** to configure the deep industry intelligence templates.

## 1. UI/UX Paradigm: "Focus Mode"

Based on the Interaction Onboarding Framework:

- **Interface Reduction:** When the wizard is active, the standard dashboard shell is suppressed. The sidebar is fully closed/removed, and top navigation is hidden.
- **Big Screen Focus:** A distraction-free, full-bleed interface focusing solely on the current configuration step.
- **Progressive Saving:** Every click emits an `ENGINE_SYSTEM_EVENT_ENVELOPE` event (`step_completed`, `data_saved`). The user can safely drop off and resume without data loss.

---

## 2. The Workflow Steps (What to select)

The goal of the first run is **Configuration through Elimination**. Because our Supabase templates already contain the full standard (e.g., 50+ procedures for restaurants), the admin simply toggles what _doesn't_ apply, or adds specifics.

### Step 1: Location Specifics (Lokasjonsspesifikt)

Focuses on the physical realities of the workspace.

- **Matservering (Food Service):** Toggle on/off. (Activates HACCP, Mattilsynet compliance, temperature logs, hygiene rules).
- **Brann (Fire Safety):** Confirm fire safety responsibility. (Activates evacuation procedures and fire safety control lists).
- **Kassesystem (POS):** Select POS integration or manual cash handling. (Activates Z-report routines, cash settlement procedures).
- **Allergier (Allergens):** Confirm EU 14 allergen handling. (Activates cross-contamination protocols, menu allergen matrices).

### Step 2: Orientation & Instructions (Orientering & Instrukser)

Focuses on company culture and baseline compliance.

- **Framework:** Select the operational framework (e.g., "Standard Restaurant", "Fast Casual", "Fine Dining").
- **System Compliance:** Accept the baseline internal control (Internkontroll) auto-generated by the system.
- **Information:** Generate the first draft of the Company Handbook based on the industry intelligence profile.

### Step 3: Staffing & Budget (Bemanning & Budsjett)

Focuses on the financial and legal foundation.

- **Starting Budget:** User inputs their target season/annual revenue (e.g., NOK 8.5M).
- **Calculate & Evaluate:** The system instantly calculates the target labor percentage (e.g., 32%) and distributes it across day/hour factors using the `season_budget` engine.
- **Document Generation (Contracts):** The user can "draw up" the first employment contracts directly on the screen. The system uses the NACE code and template data (Riksavtalen) to pre-fill legal wages and terms for the core team.

### Step 4: Training Compliance - The 5 Pillars (Opplæring)

Focuses on employee readiness. The admin maps the 5 foundation pillars to their departments.

1.  **Food (Mat):** Basic food safety, hygiene, HACCP principles.
2.  **Fire Safety (Brann):** Evacuation routes, extinguisher locations.
3.  **System:** How to use Smartout (shift swapping, reading policies).
4.  **Domain Knowledge (Kunnskap):** Specifics like wine pairing, coffee brewing, or menu knowledge.
5.  **Allergies (Allergier):** Deep dive into handling allergic guests safely.

_Action:_ The admin simply clicks which departments require which pillars (e.g., Kitchen needs all 5, Bartenders need 2, 3, 4). The system automatically generates the `protocol_assignments` for all future employees in those departments.

---

## 3. Tracking & The State Engine

How we track this in the **Core State Engine**:

- **Mission Binding:** This wizard operates under a specific Mission ID (e.g., `M-002-SETUP`).
- **Workspace Readiness Score:** Instead of just tracking employee readiness, we track **Workspace Readiness**. Completing this wizard moves the workspace from `setup_pending` to `fully_operational`.
- **Sensory Runtime (Guardian):** If the admin completes 3 out of 4 steps and leaves, the Guardian uses the "Smell" anomaly signal (stalled flow) to send a low-risk "Nudge" notification after 24 hours: _"You are one step away from a fully compliant workspace. Finish your Training Compliance setup."_
