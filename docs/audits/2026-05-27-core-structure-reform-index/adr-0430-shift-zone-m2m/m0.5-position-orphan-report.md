# M0.5 Position-Orphan Reconciliation Report

## Query executed

```sql
SELECT s.schedule_shift_id, s.position_id
FROM schedule_shift s
LEFT JOIN position p ON s.position_id = p.position_id
WHERE s.department_id IS NULL
  AND s.position_id IS NOT NULL
  AND p.department_id IS NULL;
```

## Interpretation

Zero orphan rows found. No `schedule_shift` row exists where:
- `department_id` is NULL, AND
- `position_id` is NOT NULL, AND
- the linked `position` row also has `department_id` NULL

This means the M1 backfill (`UPDATE schedule_shift SET department_id = p.department_id FROM position p WHERE schedule_shift.position_id = p.position_id AND schedule_shift.department_id IS NULL`) will not encounter any position rows with missing `department_id` — no backfill dead-ends.
