# On boarding

## Syfte

Beskriva onboardingflodet for nya ansatte, fran inbjudan till jobbklar status.

## Innehall (start)

- Inbjudan och registrering
- Dokument och signering
- Traning och progression
- Trainee till aktiv status

## Generic text (MVP)

On boarding ska vara enkel, tydlig och uppfoljbar.  
Mallet ar att nya ansatte snabbt blir trygga och produktiva utan att tumma pa kvalitet.

## User story (utkast)

Som personalansvarig vill jag ha ett strukturerat onboardingflode sa att nya ansatte blir jobbklara snabbare.
