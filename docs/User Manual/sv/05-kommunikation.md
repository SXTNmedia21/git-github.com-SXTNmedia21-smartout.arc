# Kommunikation

## Syfte

Visa hur teamet skickar information, varningar och driftmeddelanden i Smartout.

## Innehall (start)

- Team-chat
- Dagsinformation
- Push/SMS/e-post
- Malar for snabb kommunikation

## Generic text (MVP)

God kommunikation minskar missforstand och sparar tid i vardagen.  
I denna guide beskriver vi hur ni valjer ratt kanal for ratt meddelande.

## User story (utkast)

Som ledare vill jag kunna skicka tydliga meddelanden till ratt personer sa att driften flyter utan onodiga avbrott.
