# Rapporter

## Syfte

Beskriva hur ni foljer upp schema, kostnad, onboarding och kvalitet med rapporter.

## Innehall (start)

- Operativ dagsstatus
- Vecko- och manadstrender
- Personalkostnad och bemanningsgrad
- Export for vidare analys

## Generic text (MVP)

Rapporter ger ledning och team samma bild av laget.  
Fokus ligger pa att hitta avvikelser tidigt och fatta battre beslut snabbare.

## User story (utkast)

Som admin vill jag se tydliga rapporter sa att jag kan styra drift, kostnad och kvalitet med fakta.
