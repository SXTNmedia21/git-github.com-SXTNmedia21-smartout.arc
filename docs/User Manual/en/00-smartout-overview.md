# What is Smartout, and how do you use it?

Smartout is an operational system for shift-based businesses in Norway.
It ties together onboarding, staffing, training, daily operations, reconciliation and communication in a single workflow system.

The core idea is simple:

**Is the team ready for the shift?**

## Smartout in one sentence

Smartout helps you plan, execute and follow up every working day with clear accountability, traceability and AI assistance.

## Who Smartout is built for

- Restaurants
- Cafes
- Hotels
- Retail and other shift-based businesses

## How the system is built

Smartout has three intelligence layers:

1. **System Intelligence**
   Runtime, process flow, status, gates, and control over what is actually happening in the platform.

2. **Industry Intelligence**
   Industry adaptation for hospitality: suggestions for structure, policies, procedures and relevant training.

3. **Artificial Intelligence (the Botsson layer)**
   Conversational layer for onboarding and daily assistance. The agent can read context, suggest actions and control UI flows where enabled.

## The agents in practice

- **Botsson (`onboarding-interview`)**
  Leads the onboarding setup for a new workspace.

- **Mr. Botsson (`mr-botsson`)**
  Dashboard assistant for daily operations (shifts, training, operations, HACCP).

- **Specialist agents**
  Examples: HACCP inspector and shift assistant for specific needs.

## How to use Smartout (recommended flow)

## 1) Set up the workspace (admin onboarding)

Start in onboarding and build the foundation:

- verify the business
- set the season
- add departments, locations and procedures
- complete workspace activation

Result: you have an operational workspace with structure and clear areas of responsibility.

## 2) Invite employees

Invite via email, SMS or link.
New users get a profile and can start the trainee/onboarding flow after setup.

## 3) Run daily operations from the dashboard

Use the dashboard to:

- follow up on shifts and coverage
- view readiness/training status
- handle daily tasks and deviations
- ensure the day ends with control and sign-off

## 4) Use the communication layer actively

Communication in Smartout is operational, not social noise:

- channels for team/department/session
- notifications by priority
- critical events escalated through the right channel

## 5) Use Botsson where it adds value

Botsson is best used for:

- onboarding guidance
- quick navigation in the system
- explaining status and next steps
- help in complex or time-critical situations

## What is live now vs. under further development

### Live now

- Admin onboarding flow in the app
- Voice/chat-based agent infrastructure (mission-based)
- Key parts of services/health and operational foundation

### Under further development

- Full trainee mode with complete checkpoint system
- Deeper module journeys per employee
- More advanced AI-driven training and automatic follow-up logic

This is intentional: Smartout is built incrementally with reliable deliveries.

## Regional focus: Norway

Smartout is designed for Norwegian conditions:

- Breg verification in the onboarding flow
- Focus on the Norwegian Food Safety Authority (Mattilsynet)/HACCP traceability in operations
- Support for workflows where accountability, deviations and sign-off must be clearly documented

## A simple rule of thumb for the team

- **Before a shift:** check status, coverage and readiness
- **During a shift:** use tasks, session flow and chat operationally
- **After a shift:** complete handoff/sign-off with clear deviations and next steps

When this is in place, Smartout becomes more than just a system you use — it becomes the way operations are actually run.
