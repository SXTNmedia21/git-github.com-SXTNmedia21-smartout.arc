# HACCP / MAT-Syn

## Syfte

Samla riktlinjer och arbetsfloden for internkontroll, livsmedelssakerhet och uppfoljning mot myndighetskrav.

## Innehall (start)

- HACCP-grund
- Kontrollpunkter och dokumentation
- Avvikelsehantering
- Rapporter for tillsyn

## Generic text (MVP)

Denna sida ar till for att gora compliance praktisk i vardagen.  
Mallet ar att teamet vet vad som kravs, nar det kravs och hur det foljs upp.

## User story (utkast)

Som kvalitetsansvarig vill jag ha tydliga HACCP/MAT-Syn-floden sa att vi kan dokumentera korrekt och sta redo for tillsyn.
