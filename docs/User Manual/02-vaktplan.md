# Vaktplan

## Syfte

Beskriva hur ledare bygger, justerar och publicerar schema i Smartout.

## Innehall (start)

- Vyval: Ansatt, Jobb, Team
- Tidslage: Dag, rullerende, manad, lista
- Drag-and-drop av vakter
- Publicering och varsling

## Generic text (MVP)

Vaktplanen ar navet for daglig bemanning.  
I denna guide visar vi hur ni bygger en fungerande plan, hittar luckor och publicerar till teamet.

## User story (utkast)

Som schemalaggare vill jag skapa och publicera en tydlig vaktplan sa att teamet vet vem som jobbar nar.
