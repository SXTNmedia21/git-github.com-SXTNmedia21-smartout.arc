# LISA / AI-assistent och installningar

## Syfte

Beskriva hur LISA AI-assistent anvands i drift samt hur viktiga installningar satts och forvaltas.

## Innehall (start)

- Vad LISA kan hjalpa till med
- AI-stod i schema och kommunikation
- Viktiga installningar for verksamheten
- Ansvar, roller och guardrails

## Generic text (MVP)

LISA ska fungera som en praktisk assistent for ledare och team.  
Installningarna pa denna sida styr hur Smartout beter sig i vardagen och bor ses over regelbundet.

## User story (utkast)

Som admin vill jag kunna styra LISA och installningar tydligt sa att AI-stodet blir tryggt, relevant och nyttigt for verksamheten.
