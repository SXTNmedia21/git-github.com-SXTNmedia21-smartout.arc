# Rutiner

## Syfte

Beskriva standardrutiner som ska upprepas varje dag, vecka eller period.

## Innehall (start)

- Oppningsrutiner
- Mellanrutiner
- Stangningsrutiner
- Kvalitetskontroll och signoff

## Generic text (MVP)

Rutiner skapar konsekvent kvalitet over tid.  
Med tydliga rutiner blir onboarding snabbare och avvikelser enklare att hitta.

## User story (utkast)

Som driftsansvarig vill jag standardisera rutiner sa att kvaliteten blir jamn oavsett vem som jobbar.
