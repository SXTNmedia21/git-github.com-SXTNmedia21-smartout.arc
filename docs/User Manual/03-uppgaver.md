# Uppgaver

## Syfte

Samla alla dagliga uppgifter som maste goras per pass, avdelning eller roll.

## Innehall (start)

- Oppgavelistor per dag
- Tildelning till person eller team
- Status: pending/in progress/completed
- Uppfoljning i dashboard

## Generic text (MVP)

Uppgaver hjalper teamet att veta exakt vad som ska goras.  
Mallet ar mindre ad hoc-arbete och mer forutsagbar drift.

## User story (utkast)

Som skiftledare vill jag ha tydliga uppgifter for varje pass sa att inget viktigt missas.
