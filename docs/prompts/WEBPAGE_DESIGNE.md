🧠 World-Class Website Prompt Template (Epic Quality)

Använd som top-level prompt när du ber AI att skapa hemsida, landningssida, designkoncept, komponenter eller fullständig implementation.

Instruction to the AI:
Generate a complete, world-class website design and content specification that is professional, conversion-focused, visually impactful, and ready for implementation (HTML/CSS/React/TSX code where relevant). Be specific about purpose, target audience, structure, layout, design language, content hierarchy, user journey, brand tone, accessibility, and performance. Do not produce generic layouts; instead produce intentional, differentiated, and strategic results.

🧩 1) Project Foundation

Website identity & intent

Purpose: [e.g., SaaS landing page / portfolio / e-commerce]
Target audience: [specific persona demographics & motivations]
Core conversion goal: [primary CTA — e.g., sign-up, purchase]
Key value proposition: [unique, outcome-focused sentence]
Brand personality: [e.g., bold enterprise, minimalist premium, playful startup]

Context-driven market positioning

Competitive differentiation: [what makes this distinct in category]
Industry norms to avoid: [generic patterns to exclude]
Tone & voice: [precise voice direction for copy]

AI bör först definiera och strukturera kontexten — inte bara svara på yta.

🧱 2) Architecture & Structural Blocks

Primary structural blueprint

Hero → Problem → Agitation → Solution → Mechanism → Proof → Social proof → Primary CTA → Secondary CTA → Footer

För varje block, specificera:

1. Purpose of the block
2. Headline (impactful + benefit-driven)
3. Sub-headline (clarifies transformation)
4. Visual guidance (layout + imagery + style cues)
5. Engagement mechanism (animation/Micro-interaction direction)

Functional UI blocks

Navigation: [persistent, sticky, CTA integrated]
Feature showcase: [icon + headline + micro-proof line]
Testimonials: [persona, context, metric if available]
Pricing matrix: [tiers, justification, contrast highlights]
Frequently Asked Questions: [user pain/objection handling]
Footer: [trusted partner logos, secondary CTAs, site links]

En sån sekvens gör designen strategiskt strukturerad och konverteringsdriven.

🎨 3) Design & Aesthetics Instructions

Visual and layout directives

Typeface hierarchy: [primary, secondary, weights]
Color palette: [primary, secondary, accents + hex codes]
Spacing system: [baseline grid, margin/padding guidelines]
Visual style: [minimal premium / modern enterprise / dramatic contrast]
Imagery guidelines: [hero image vibe, icons style, illustration direction]
Accessibility requirements: [WCAG AA contrast levels minimum]
Responsive behavior: [breakpoints + layout shifts]

Design intent language

"High typographic hierarchy"
"Intentional whitespace, not empty space"
"Bold anchor CTA color with subtle supporting tones"

Det här triggar design-intention, inte bara “pretty”…

✍️ 4) Copy & Messaging Precision

Messaging constraints

Headlines: outcome-first, short, declarative  
Paragraphs: one idea per sentence  
Microcopy: explicit action language (e.g., “Get started — instant access”)  
Avoid: buzzwords, generic claims, overused startup phrasings

Core copy blocks

Hero headline & sub-text  
Pain statement  
Transformational promise  
Feature benefit pairs  
Proof headlines  
CTA copy variants  
SEO meta titles & descriptions

Genom att rikta AI mot specifik copy-disciplin, får du mer affärseffekt.

🛠 5) Implementation Output Targets

Om du vill ha kod:

- Provide production-ready HTML/CSS/JS or React/TSX.
- Use semantic HTML5.
- Ensure mobile-first responsive classes.
- Include animation specs (prefer CSS transitions or JS hooks).
- Export screenshots of layout blocks as drafts.

Om du vill ha design abstract:

- Provide Figma/Sketch component system description
- Provide tokens for spacing, color, typography
  📌 6) Quality Filters & Anti-Fluff Rules

Add the following instructions at end of every prompt:

Avoid generic placeholders  
Do not use words like “innovative solution”, “cutting-edge” without context  
Do not produce stock layout dumps  
Every section must have a strategic justification  
Be explicit, no assumptions or vague outputs

Detta är avgörande för att kalibrera agenten bort från mediokritet.

Then paste template below with your project specifics filled in.
