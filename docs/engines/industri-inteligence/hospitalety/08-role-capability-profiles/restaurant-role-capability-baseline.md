# Restaurant Role Capability Baseline

## Core Roles (foundation set)

### 1) Shift Leader

- Core knowledge: service flow, staffing response, escalation rules, key policies
- Core skills: prioritization, delegation, incident handling, close signoff
- Required trainings: opening/closing pipeline, incident/deviation handling, fire safety
- Ready signal: can run one full shift cycle without policy-critical misses

### 2) Waiter / Service Operator

- Core knowledge: menu basics, allergen communication, service standards
- Core skills: order flow, guest communication, handoff to kitchen
- Required trainings: allergen handling, service safety, communication protocol
- Ready signal: completes full service sequence with correct allergen handling

### 3) Cook / Kitchen Operator

- Core knowledge: food safety, temperature control, traceability basics
- Core skills: prep execution, safe handling, quality consistency
- Required trainings: HACCP basics, temperature logging, hygiene control
- Ready signal: executes prep + service tasks with compliant temperature and hygiene behavior

### 4) Bartender / Bar Operator

- Core knowledge: age control, serving constraints, service quality standards
- Core skills: service throughput, ID verification, refusal handling
- Required trainings: alcohol service control, de-escalation basics
- Ready signal: handles bar service and age checks without compliance breaches

### 5) Cleaner / Hygiene Operator

- Core knowledge: sanitation standards, zone priorities, contamination prevention
- Core skills: checklist completion, hygiene verification, issue reporting
- Required trainings: daily/weekly cleaning routines, hygiene safety
- Ready signal: completes hygiene controls with verifiable checklist quality

## Notes

- Start with these five roles for foundation speed.
- Add specialist variants (catering/event/sommelier) after baseline is stable.
