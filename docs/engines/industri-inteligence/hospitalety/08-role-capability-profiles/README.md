# Role Capability Profiles

## Purpose

Define what people in each role need to know and be able to do.

This is the missing bridge between templates/policies and training/readiness.

## Minimal Structure

Each role profile should include only:

- Role name
- Core knowledge
- Core skills
- Required trainings
- Optional advanced trainings
- Readiness signal (what "ready" means for this role)

## Usage

- Onboarding plans
- Training assignment and verification
- Journey expectations by role
- Testing persona alignment
