# Niche Profiles

## Purpose

Niche is the specialization layer inside an industry.

Industry says what domain we operate in. Niche says how this specific business operates inside that domain.

## Why this layer is critical

- It prevents one-size-fits-all assumptions.
- It tunes persona, skill, journey, and testing priorities.
- It lets the system apply weighted focus after company setup.
