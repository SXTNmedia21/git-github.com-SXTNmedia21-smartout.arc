# Frontend Designer Agent Spec (Legacy Reference)

This document is now a supplemental design reference only.

- `docs/agents/frontend-design/SUBAGENT_SPEC.md`

Use that file for:

- agent scope and non-scope

- implementation and verification expectations

Keep this file for historical framing and aesthetic intent, not as a source of operational rules.

## Historical Design Intent

- Prioritize tactile, high-quality interfaces over generic component output
- Treat motion as communication, not decoration
- Use typography and spacing to create hierarchy before adding visual chrome
- Reduce unnecessary borders and layers to improve clarity
