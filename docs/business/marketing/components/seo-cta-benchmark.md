## 3. CTA-hierarki

### 3.1 Konverteringstrakt

```
OPPMERKSOMHET → INTERESSE → VURDERING → HANDLING
Google/SoMe   Qualifier   Prissiden    Signup
              Pain Sel.   Comparison
              Action Grid Testimonials
              Features
```

### 3.2 CTA-plassering

| CTA              | Type           | Tekst                   | Mål                   | Plassering            |
| ---------------- | -------------- | ----------------------- | --------------------- | --------------------- |
| Header           | Primær (liten) | Start gratis            | /signup               | Sticky, alltid synlig |
| Hero primær      | Primær         | Start gratis nå         | /signup               | Hero                  |
| Hero sekundær    | Ghost          | Se hvordan det fungerer | scroll #qualifier     | Hero                  |
| Website CTA      | Primær         | Få din gratis nettside  | /signup               | Feature website       |
| Feature CTA      | Tekstlenke     | Les mer →               | /features/X           | Feature-deep          |
| Pricing Free     | Sekundær       | Start gratis            | /signup               | Pricing preview       |
| Pricing Standard | Primær         | Kom i gang              | /signup?plan=standard | Pricing preview       |
| AI CTA           | Primær         | Start gratis nå         | /signup               | AI-seksjon            |
| Final CTA        | Primær (stor)  | Start gratis nå         | /signup               | Final CTA banner      |

### 3.3 CTA per persona (dynamisk)

| Persona | Primær CTA      | Sekundær CTA         |
| ------- | --------------- | -------------------- |
| Owner   | Start gratis nå | Se priser            |
| Manager | Start gratis nå | Del med sjefen din   |
| HR      | Book en demo    | Se opplæringsmodulen |
| Ops     | Kontakt oss     | Se enterprise-pakken |

### 3.4 CTA-regler

- Maks 1 primær CTA synlig samtidig (utenom header)
- Aldri "Book demo" som primær for SMB — de vil prøve selv
- "Start gratis" > "Opprett konto" — verdi fremfor handling
- Aldri pris i CTA-tekst
- Ghost CTA alltid under primær
- Mobil: CTA full bredde
- Header CTA forsvinner aldri

## 8. SEO vs. Personalisering

| Utfordring                         | Løsning                                                                                                       |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Google ser universell variant      | Server-render universell. Personalisering client-side etter hydration.                                        |
| Dynamisk innhold og indeksering    | Universelt innhold i H1, meta, første seksjon — alt crawlbart.                                                |
| Bransjevarianter, samme URL        | Én forside med universelt SEO-innhold. Varianter er visuell tilpasning, ikke separate sider.                  |
| Canonical                          | Ingen issue — alt er samme URL.                                                                               |
| Fremtidig: bransjespesifikke sider | `/restaurant`, `/hotell`, `/kafe`, `/bar` — 100% server-rendret, eget SEO. Bygges når trafikk rettferdiggjør. |
