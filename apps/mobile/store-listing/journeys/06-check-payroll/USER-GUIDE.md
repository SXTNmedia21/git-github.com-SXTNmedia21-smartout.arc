# Sjekk lønnen din

Denne guiden viser deg hvordan du ser lønnsestimat og lønnslipp.

---

## Steg 1: Åpne appen

Trykk på **Smartout-ikonet** på telefonen. Du kommer til hjemskjermen.

## Steg 2: Gå til Min Side

Trykk på **"Min Side"**-fanen nederst på skjermen.
Du ser din profilside med oversikt over:

- Profil og innstillinger
- Lønnsestimat
- Dokumenter

## Steg 3: Se lønnsestimat

Under **"Lønn"** ser du:

- **Estimert lønn denne måneden** (f.eks. 28 450 kr)
- **Timer jobbet** (f.eks. 142 t)
- **Tillegg** (kveld, helg, helligdag)

## Steg 4: Trykk på lønnslipp

Trykk på **lønnsestimat-kortet** eller **"Se detaljer"**.
Du kommer til lønnslipp-detaljsiden.

## Steg 5: Se beregningen

På detaljsiden ser du en fullstendig oversikt:

- **Grunntimer** — antall timer x timelønn
- **Kveldstillegg** — timer etter kl. 21:00 x tilleggssats
- **Helgetillegg** — timer lørdag/søndag x tilleggssats
- **Helligdagstillegg** — timer på røde dager x tilleggssats
- **Totalt** — summen av alt

Hver linje viser antall timer og sats, slik at du kan dobbeltsjekke.

**Nå vet du hva du tjener og hvorfor!**
